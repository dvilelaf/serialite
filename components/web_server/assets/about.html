About Serialite

Terminal Config Firmware

Serial rescue console over a local WiFi access point. It is not a video KVM: no HDMI, no remote keyboard or mouse, no virtual media, no host power control and no cloud access.

Before typing

  1. Make sure you joined the right access point and are physically next to the server.
  2. Check that the USB link is up and that the drop counters in Diagnostics are not climbing.
  3. Wait for console output before sending commands.

Recovering access

  1. The open web session has the keyboard. Opening the console elsewhere takes it over.
  2. Start with low-risk commands: ip addr, ip route, systemctl status, journalctl -xb.
  3. Avoid pasting long blocks. Large pastes ask for confirmation and are sent in chunks, but they still run on the real console.

If something fails

  1. USB shown as lost: check the cable and port, and that the server runs the Serialite getty (see the setup script).
  2. Too many requests: wait a few seconds and reload less often.
  3. Lost control of the web console: tap PWR on the device. That ends the web session and blocks new ones until PWR is tapped again.
  4. Unknown WiFi password: press BOOT to show it, or hold BOOT for 10 seconds to factory reset.
  5. Diagnostics never contain passwords; you can paste them into a ticket.

Device buttons

  • BOOT: wake the screen; press again to show the WiFi password and, with HTTPS, the certificate fingerprint.
  • BOOT held 10 s: factory reset. A countdown appears after 2 s.
  • PWR tap: emergency lock on or off. PWR held 3 s: power off.
